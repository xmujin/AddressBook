# 通讯录管理系统

## 一、系统简介

使用C++开发

## 二、功能需求

### 1. 用户密码登录功能

输入正确的用户名和密码，密码验证成功后进入主功能界面

### 2. 添加联系人功能

支持新增联系人信息，包含姓名、手机号等信息；自动检测重复联系人，避免重复录入信息.

### 3. 浏览全部联系人功能

可一键展示所有已保存的联系人数据，列表清晰展示所有字段信息。

### 4. 查询联系人功能

根据姓名定位指定联系人，支持对手机号等信息进行重新修改并更新保存。

### 5. 修改联系人功能

可以根据姓名定位联系人，再修改

### 6. 删除联系人功能

支持单独删除指定联系人，删除后自动同步保存到文件。

### 7. 数据排序功能

支持对联系人按姓名排序展示，使通讯录列表更加规整

### 8. 文件持久化


### 9. 安全容错

对非法输入、空查询、不存在联系人等异常情况进行提示。
